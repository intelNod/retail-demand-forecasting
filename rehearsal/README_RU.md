# Репетиция демонстрации Retail Demand Forecasting

Эта папка содержит всё, что нужно открыть во время локальной репетиции:

- `demo_sales_features.xlsx` — входной Excel с 240 строками защищённого test-периода;
- `expected_prediction_results.xlsx` — заранее проверенный результат той же загрузки;
- `showcase/index.html` — собственная showcase-страница проекта;
- `start_rehearsal.ps1` — запуск Flask UI и showcase.

Модель и серверный код находятся в `models/final_model/` и `src/`. Они не
копируются в эту папку второй раз, потому что запуск всегда выполняется из
корня одного Git-репозитория.

## Что находится в Excel

В `demo_sales_features.xlsx` есть две вкладки:

1. `Instructions` — короткое объяснение файла.
2. `Demo Input` — 240 примеров: четыре недели × десять магазинов × три отдела
   FOODS × две строки.

Каждая строка содержит идентификаторы, 20 признаков Random Forest и
`actual_units_sold`. Колонка фактических продаж не передаётся модели. Она
используется только после prediction для расчёта ошибки.

## Подготовка перед репетицией

Откройте PowerShell в корне проекта и выполните:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Затем запустите:

```powershell
.\rehearsal\start_rehearsal.ps1
```

Не закрывайте окно PowerShell до окончания демонстрации.

## Порядок демонстрации

1. Откройте `http://127.0.0.1:5000/showcase`.
2. Объясните проблему, pipeline, официальный test MAE и ограничение модели.
3. Нажмите `Open prediction UI`.
4. Найдите блок `Predict an Excel batch`.
5. Выберите `rehearsal/demo_sales_features.xlsx`.
6. Нажмите `Run batch prediction`.
7. Покажите четыре значения: количество строк, demo MAE, средние реальные
   продажи и средний прогноз.
8. Покажите таблицу `actual_units_sold`, `predicted_units_sold` и
   `absolute_error`.
9. Нажмите `Download prediction results`.
10. Откройте скачанный `prediction_results.xlsx` и покажите вкладки `Summary`
    и `Predictions`.

## Ожидаемый результат

Для неизменённого демонстрационного файла проверено:

| Показатель | Значение |
|---|---:|
| Строк | 240 |
| Demo MAE | 3.4419 |
| Средние реальные продажи | 6.7875 |
| Средний прогноз | 6.4392 |

Demo MAE `3.4419` относится только к выбранным 240 строкам. Официальный
результат проекта остаётся test MAE `4.4179` на всех 57 480 test-строках.

## Что сказать вслух

> Я загружаю 240 строк из защищённого test-периода. Каждая строка представляет
> товар, магазин и неделю. Модель получает только 20 признаков: прошлые
> продажи, цены и известные календарные данные. Фактические продажи скрыты от
> модели и используются только после прогноза для расчёта абсолютной ошибки и
> MAE. Этот небольшой rehearsal-файл нужен для быстрой демонстрации; официальный
> test MAE рассчитан отдельно на всех 57 480 строках.

## Если что-то не работает

- `Model unavailable` — дождитесь загрузки модели и обновите страницу.
- Не принимается файл — проверьте расширение `.xlsx` и вкладку `Demo Input`.
- Missing required columns — используйте исходный `demo_sales_features.xlsx`
  и не переименовывайте колонки.
- Порт занят — закройте старое окно сервера и снова запустите скрипт.
- Остановить сервер — нажмите `Ctrl+C` в PowerShell.
